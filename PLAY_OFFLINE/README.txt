GAIA CLIMATE LAB v9 — OFFLINE INDEX.HTML EDITION
================================================

QUICK START
-----------
1. Extract the ZIP before launching the game.
2. Open the PLAY_OFFLINE folder.
3. Double-click index.html.

That is all. No npm install, npm build, terminal, local server, or internet
connection is required.

WHAT IS INCLUDED
----------------
- The same v9 simulation and interface as the published build
- WebGL2 hardware-accelerated planet graphics, with a software fallback
- Climate, atmospheric composition, water phase, escape, and carbon-cycle model
- Live-change and reset-on-change input modes
- Click-to-type exact values as well as sliders
- Accelerated, refresh-rate-independent simulation time
- English interface by default, with optional Slovak

OFFLINE NOTES
-------------
- Keep index.html, gaia-climate-lab.js, gaia-climate-lab.css, and favicon.svg
  together in this folder.
- The browser address begins with file:// because this edition runs directly
  from your computer. That does not change the simulation.
- Links to scientific references need an internet connection. The game itself
  does not.
- Simulations are not synchronized with the published website or another
  computer.
